# SAQ Qurylys

Цифровой помощник уполномоченного органа (ДЭР / ГАСК ВКО) для мониторинга рекламы долевого строительства и риск-скоринга жилых комплексов Усть-Каменогорска. Codemasters 8.0.

> ИИ формирует рекомендацию, решение о нарушении принимает аналитик. Все ЖК, застройщики, БИН и объявления в демо-наборе **вымышлены**.

## Экраны

Интерфейс собран в визуальном языке сервисов Яндекса. Основной образец — Яндекс Недвижимость (раздел «Новостройки»): шапка с вкладками, полоса фильтров «Комнат ⌄», выдача ЖК карточками, страница ЖК с панелью «Об объекте», метки-ценники на карте. Панель на карте — как у Яндекс Go, круглые цветные категории — как у Яндекс Карт. Палитра: текст `rgba(0,0,0,.92)`, серые кнопки `#F3F1F1`, жёлтый `#FED42B`, ссылки `#0065D9`, семантика зелёный `#00B341` / оранжевый `#F59D00` / красный `#E4402D`.

- UI-кит: `frontend/src/styles/go.css`
- Иконки: [Gravity UI Icons](https://gravity-ui.com/icons) — открытая (MIT) библиотека дизайн-системы Яндекса (`frontend/src/ui/icons.tsx`)
- Логотипы площадок: Simple Icons (CC0) для Instagram, TikTok, Telegram, Facebook; фавиконки сайтов Krisha, OLX, 2ГИС (`frontend/public/brands`)
- Шрифт: Onest (OFL); фирменный YS Text проприетарный и в репозиторий не включён

| Путь | Экран |
|---|---|
| `/login` | Вход сотрудника |
| `/` | Карта: поиск ЖК, фильтр по зонам, список, карточка объекта, промо-плашки |

| `/ads/:id` | Разбор публикации: OCR, сигналы, история, решение аналитика |
| `/ads/new` | Ручное добавление + OCR скриншота, оценка на лету |
| `/queue` | Очередь проверки: доска с перетаскиванием |
| `/developers` | Застройщики |
| `/sites` | Фото-мониторинг (доп. модуль) |
| `/method`, `/sources`, `/reports`, `/residents` | Методика, источники, отчёты, идея push жителям |

## Запуск

### Docker (Postgres + API + фронт)

```bash
docker compose up --build
# фронт  http://localhost:5180
# API    http://localhost:8000/docs
```

### Локально одной командой

```bash
./dev.sh        # API :8000 (SQLite) + фронт :5180
```

Сброс демо-данных: удалить `backend/saq.db` и перезапустить.

### Тесты

```bash
cd backend && .venv/bin/python -m pytest -q
cd frontend && npx tsc -b   # проверка типов
```

### Локально вручную

```bash
# бэкенд (без Postgres можно на SQLite)
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
DATABASE_URL=sqlite:///./saq.db .venv/bin/uvicorn app.main:app --reload --port 8000

# фронтенд
cd frontend
npm install
npm run dev            # http://localhost:5180, /api проксируется на :8000
```

Фронтенд работает и без бэкенда, на встроенном демо-наборе (`frontend/src/data/demo.ts`).

## Скоринг

| Код | Фактор | Баллы |
|---|---|---|
| R1 | Нет основания для привлечения средств (гарантия ЕО / МИО + БВУ) | 35 |
| R2 | Реклама продажи на стадии строительства | 30 |
| R3 | Нет в опубликованном перечне ГАСК | 10 |
| R4 | Простой стройки по снимкам (30+ / 90+ дней) | 5 / 10 |
| R5 | Признаки сбора денег в тексте (бронь, взнос, ДДУ…) | 10 |
| R6 | Профиль застройщика | 10 |

`red` — score ≥ 60 **и** подтверждены R1 + R2; `yellow` — score ≥ 25; иначе `green`. Нет сведений → 0 баллов и «Нужна проверка».

## Стек

React 19 + TypeScript + Vite, собственный UI-кит, MapLibre GL (подложка CARTO / OpenStreetMap) · FastAPI, SQLAlchemy 2, PostgreSQL 16 · Tesseract OCR (rus/kaz) в Docker-образе.
