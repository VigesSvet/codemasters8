# SAQ Qurylys

Цифровой помощник уполномоченного органа (ДЭР / ГАСК ВКО) для мониторинга рекламы долевого строительства и риск-скоринга жилых комплексов Усть-Каменогорска. Codemasters 8.0.

> ИИ формирует рекомендацию, решение о нарушении принимает аналитик. Все ЖК, застройщики, БИН и объявления в демо-наборе **вымышлены**.

## Экраны

| Путь | Экран |
|---|---|
| `/login` | Вход сотрудника |
| `/` | Карта-светофор города. Два варианта: **Карта** (карта + список) и **Сводка** (редакционная подача) |
| `/complexes` | Реестр ЖК: фильтры, сортировка, таблица или сетка карточек |
| `/complexes/:id` | Карточка ЖК: основания (гарантия ЕО, МИО, БВУ, перечень ГАСК), объяснение скоринга R1–R6, реклама, фото-мониторинг, застройщик |
| `/ads` | Лента публикаций с подсветкой формулировок (лента или сетка) |
| `/ads/:id` | Разбор публикации: OCR, сигналы, привязка ЖК, решение аналитика, журнал |
| `/ads/new` | Ручное добавление публикации + OCR скриншота, анализ на лету |
| `/queue` | Очередь проверки: канбан с drag-and-drop или список |
| `/developers` | Застройщики (профиль открывается в выдвижной панели) |
| `/sites` | Фото-мониторинг (доп. модуль): сравнение снимков «до/после», простой, ограждение / контейнер / мойка колёс |
| `/method` | Методика скоринга и словари ключевых слов |
| `/sources` | Источники данных |
| `/reports` | Еженедельная сводка |
| `/residents` | Идея: push-уведомления жителям (не входит в MVP) |

**Варианты дизайна** переключаются в левом нижнем углу: `Fortis` (светлая, крупный гротеск), `Siera` (тёмная, антиква + гротеск), `Banda` (тёплая песочная).

## Запуск

### Docker (Postgres + API + фронт)

```bash
docker compose up --build
# фронт  http://localhost:5180
# API    http://localhost:8000/docs
```

### Локально одной командой

```bash
./dev.sh        # API :8000 (SQLite) + фронт :5180
```

Сброс демо-данных: удалить `backend/saq.db` и перезапустить.

### Тесты

```bash
cd backend && .venv/bin/python -m pytest -q
cd frontend && npx tsc -b   # проверка типов
```

### Локально вручную

```bash
# бэкенд (без Postgres можно на SQLite)
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
DATABASE_URL=sqlite:///./saq.db .venv/bin/uvicorn app.main:app --reload --port 8000

# фронтенд
cd frontend
npm install
npm run dev            # http://localhost:5180, /api проксируется на :8000
```

Фронтенд работает и без бэкенда, на встроенном демо-наборе (`frontend/src/data/demo.ts`).

## Скоринг

| Код | Фактор | Баллы |
|---|---|---|
| R1 | Нет основания для привлечения средств (гарантия ЕО / МИО + БВУ) | 35 |
| R2 | Реклама продажи на стадии строительства | 30 |
| R3 | Нет в опубликованном перечне ГАСК | 10 |
| R4 | Простой стройки по снимкам (30+ / 90+ дней) | 5 / 10 |
| R5 | Признаки сбора денег в тексте (бронь, взнос, ДДУ…) | 10 |
| R6 | Профиль застройщика | 10 |

`red` — score ≥ 60 **и** подтверждены R1 + R2; `yellow` — score ≥ 25; иначе `green`. Нет сведений → 0 баллов и «Нужна проверка».
